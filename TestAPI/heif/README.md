These four tiny fixtures are synthetic 32×24 colour fields generated by
`generate.cpp`. The top half is RGB (220,70,30), the bottom half (30,70,220).
RGBA fixtures additionally use alpha 255 and 100. Each contains a synthetic
128-byte ICC block to verify opaque profile preservation, not colour management.
No third-party photographs or copyrighted sample images are included.

The decoder tests read the checked-in files and require only HEVC and AV1
**decoders**. Fixture generation is deliberately separate: older x265 encoders
can leak memory, which must not hide leaks in decoder tests.

To regenerate, configure FreeImage with `BUILD_LIBHEIF=ON`, install libheif's
x265 and AOM encoders, build the `GenerateHeifFixtures` target, and run it with
this directory as its working directory. These fixtures were generated using
libheif 1.23.2. Encoded bytes can differ across codec versions; tests compare
pixel values with a tolerance for lossy colour conversion.
